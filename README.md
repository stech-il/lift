# פירסום מסכי מעליות (Pirsum)

מערכת לניהול תוכן מרוחק לתצוגת מסכים במעליות: שרת ניהול, העלאת מדיה, RSS, מזג אוויר, ונגן Windows (Electron) עם מטמון מקומי ועבודה ללא אינטרנט.

## דרישות

- Node.js 18+
- במחשב המעלית: התקנה מקובץ Setup (מומלץ) או Node + `npm start` לפיתוח

## הרצת השרת

```bash
cd server
npm install
set ADMIN_SECRET=סיסמה_חזקה
npm start
```

- לוח ניהול: `http://localhost:3840/admin/index.html`
- יצירת מעלית חדשה מייצרת **טוקן** — יש להעתיק אותו לנגן במחשב המעלית.
- בלוח הניהול: **פלייליסט** — מספר סרטונים/תמונות, סדר עם ↑↓, מחיקה לפי פריט או מחיקת הכל, מצב תצוגה מקדימה, ושמירה נפרדת לטקסטים ו-RSS.
- **עדכון בזמן אמת לנגנים:** השרת משדר ב-WebSocket (`/ws`) — כל שינוי בניהול גורם לנגן במעלית למשוך מחדש את התוכן מיד (בנוסף לסנכרון תקופתי כל דקה).

### משתני סביבה

| משתנה | משמעות |
|--------|--------|
| `ADMIN_SECRET` | טוקן לכניסת מנהל (חובה בפרודקשן) |
| `PORT` | פורט (ברירת מחדל 3840) |
| `DB_PATH` | נתיב לקובץ SQLite |

## הרצת הנגן (מחשב במעלית)

```bash
cd player
npm install
npm start
```

1. לחץ על ⚙ (פינה שמאלית תחתונה).
2. הזן כתובת שרת (למשל `http://IP:3840`) והטוקן של המעלית.
3. "שמור והפעל" — המערכת תמשוך תצורה, RSS, מדיה ומזג אוויר, ותשמור במטמון מקומי.

כשאין אינטרנט, מוצג מה שנשמר לאחרונה. כשהחיבור חוזר, הסנכרון מתבצע אוטומטית (בערך כל דקה) וחיבור ה-WebSocket מתחדש.

### פרוקסי / HTTPS

אם מגישים את השרת מאחורי nginx או Caddy, יש לאפשר **שדרוג WebSocket** לנתיב `/ws` (למשל `proxy_http_version 1.1`, `Upgrade`, `Connection`). כתובת הנגן חייבת להתאים ל־`http`/`https` (הנגן יוצר `ws`/`wss` בהתאם).

### מסך מלא

```bash
npx electron . --fullscreen
```

(או הוספת `fullscreen: true` ב-`electron-main.cjs` לקבוע.)

### קובץ התקנה ל-Windows (תוכנה למחשב)

הנגן בנוי ב־**Electron**. אפשר לייצר **מתקין** (אשף התקנה, קיצור דרך וכו') עם **electron-builder**:

```bash
cd player
npm install
npm run dist:win
```

- התוצאות נשמרות בתיקייה `player/dist/` — קובץ בשם דומה ל־**`Pirsum Player Setup … .exe`**.
- להריץ את ה־exe על מחשבי המעלית (או להעתיק דרך רשת / USB).
- **חתימת קוד:** אם אין חתימה מסחרית, Windows עשוי להציג אזהרת SmartScreen — אפשר לבחור «מידע נוסף» → «הרץ בכל זאת», או לרכוש תעודת חתימה ולהגדיר אותה ב־electron-builder בהמשך.

## מה כלול בממשק

- **למעלה:** שם המתקן/מעלית, שעה, תאריך, מזג אוויר (Open-Meteo לפי קו"ר/קו"א מההגדרות).
- **בצד:** טקסט גלילה אנכי (שדה "טקסט משני" בניהול).
- **מרכז:** תמונה או וידאו בלופ.
- **למטה:** כותרות מ-RSS (השרת מושך את ה-RSS כדי לעקוף מגבלות CORS).

## אבטחה

- שנה `ADMIN_SECRET` ואל תחשוף את פורט השרת לאינטרנט בלי HTTPS והגדרות firewall.
- טוקן מעלית מאפשר גישה לתוכן של אותה מעלית בלבד.

## הרחבות אפשריות

- HTTPS (nginx / Caddy) ותעודה.
- חתימת קוד (code signing) על קובץ ה־Setup של הנגן.
- חתימה על כתובות מדיה במקום `?token=` ב-query.
